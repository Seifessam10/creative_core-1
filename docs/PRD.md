# PRD — Creative Core Website
**Version**: 1.0 | **Status**: Active | **Domain**: creativecore.pro

---

## Problem
Creative Core currently relies on Instagram DMs for client acquisition. No central hub, no structured inquiry flow, no way to showcase work professionally at scale.

## Solution
A dark editorial-grade portfolio site that matches the brand's streetwear-meets-luxury aesthetic. Showcases projects, communicates services, and converts visitors into clients.

---

## Target Audiences
| Audience | Goal |
|----------|------|
| Streetwear brands | Find a designer for apparel mockups |
| Creative agencies | Outsource design output to a specialist |
| Direct clients | Commission logo / identity / campaign work |

---

## Pages
| # | Route | Purpose |
|---|-------|---------|
| 1 | `/` | Hero — first impression, marquee of work |
| 2 | `/work` | Portfolio grid — filterable project gallery |
| 3 | `/work/[slug]` | Project detail — deep dive per project |
| 4 | `/services` | What CC offers + pricing |
| 5 | `/about` | Studio story, founder, philosophy |
| 6 | `/contact` | Structured client inquiry form |
| — | `/studio` | Sanity CMS (password protected) |

---

## Design Principles
1. **Let the work dominate** — sparse UI, work is the hero
2. **Underground luxury** — not corporate, not generic
3. **Chrome is the only accent** — no rainbow colors
4. **Gravity, not bounce** — animations feel weighted
5. **Every pixel intentional** — no filler sections
